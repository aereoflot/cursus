# 🌀 A-Maze-ing Generator

[cite_start]*This project was created as part of the 42 curriculum by ancrodri.* [cite: 240]

## 📝 Description
[cite_start]A-Maze-ing is a procedural maze generator written in Python 3.10+[cite: 75, 241]. [cite_start]It creates "perfect" mazes (single path connectivity) using graph theory algorithms[cite: 13, 112]. [cite_start]The project features an interactive terminal interface, ASCII visualization, and a reusable module architecture[cite: 113, 191, 219].

## 🏗️ Architecture
[cite_start]The project is split into a reusable generator class and a main application controller[cite: 220].
